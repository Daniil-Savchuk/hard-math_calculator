# Назва проєкту: hard-math_calculator

**Проблема:** Під час розв'язання об'ємних задач з методів оптимізації (двоїстим, симплекс-методом і тд.) дуже легко припуститися дрібної арифметичної помилки під час перерахунку матриць, що повністю руйнує кінцевий результат. Пошук таких помилок вручну в багатокрокових таблицях є виснажливим процесом, який забирає багато часу.

**Рішення:** Застосунок працює як розумний математичний асистент, який не просто видає фінальну відповідь, а детально розписує кожну дію та генерує проміжні симплекс-таблиці для кожної ітерації. На початковому етапі буде реалізовано алгоритми для декількох методів. У майбутньому функціонал буде розширено для вирішення практичних задач (наприклад, проведення аналізу на чутливість для класичної задачі про фарби), щоб користувач міг легко звіряти власні ручні розрахунки з еталонними.

**Цільовий користувач:** Студенти технічних, комп'ютерних та економічних спеціальностей, які вивчають дослідження операцій чи методи оптимізації та потребують надійного інструменту для самоперевірки практичних завдань.

# User Stories:
**US1**: Як студент, я хочу вводити коефіцієнти цільової функції та систему обмежень у зручну матричну форму, щоб швидко розв'язати задачу двоїстим симплекс-методом.

**US2**: Як користувач, я хочу бачити всі проміжні ітерації (симплекс-таблиці) на окремих екранах, щоб мати можливість покроково звірити їх зі своїми розрахунками в зошиті.

**US3**: Як користувач, я хочу мати базовий набір шаблонів (наприклад, класична "задача про фарби"), щоб не вводити стандартні параметри вручну під час тестування функціоналу.

# Вимірювані обмеження:
**Performance**: Час обчислення задачі з матрицею розміром до 5x5 та генерації всіх проміжних кроків не повинен перевищувати 1 секунду на мобільному пристрої.

**Availability**: Застосунок має виконувати всі математичні обчислення локально (100% offline) без необхідності підключення до Інтернету, що критично важливо для використання в аудиторіях.

**Compatibility**: Застосунок повинен стабільно працювати на пристроях з ОС Android версії 8.0 (API Level 26) та вище.

# Дизайн ключових ендпоінтів:
**POST /api/v1/solver/dual-method**:

Опис: Приймає початкові дані задачі лінійного програмування та повертає покроковий розв'язок двоїстим методом.

Request:

```json
{
  "objective": "max",
  "c_coefficients": [3, 2],
  "constraints": [
    {
      "coefficients": [1, 2],
      "sign": "<=",
      "value": 4
    },
    {
      "coefficients": [2, 1],
      "sign": "<=",
      "value": 5
    }
  ]
}
```
**Response (200 OK)**:
```json
{
  "status": "success",
  "optimal_value": 8.5,
  "solution_variables": {
    "x1": 2.0,
    "x2": 1.5
  },
  "iterations": [
    {
      "step": 1,
      "matrix_state": [
        [...], 
        [...]
      ]
    }
  ]
}
```

# Тест-кейси:
**Test Case 1: Успішний розрахунок задачі**:

Given: користувач ввів коректні коефіцієнти для задачі, яка має оптимальний розв'язок.

When: він натискає кнопку "Розрахувати".

Then: система показує фінальну відповідь та генерує список таблиць з покроковим розв'язанням.

**Test Case 2: Валідація порожніх полів**:

Given: користувач залишив одне з полів введення коефіцієнтів у матриці обмежень порожнім.

When: він намагається запустити розрахунок.

Then: система блокує дію, підсвічує порожнє поле та виводить повідомлення про помилку "Будь ласка, заповніть усі коефіцієнти".

**Test Case 3: Обробка задачі без розв'язку**:

Given: користувач ввів систему обмежень, яка є суперечливою (немає допустимої області розв'язків).

When: система виконує алгоритм оптимізації.

Then: застосунок зупиняє розрахунок і виводить повідомлення "Задача не має розв'язку: область допустимих значень порожня".

# 🚀 Розгортання та Запуск

**🌐 Публічний URL (Render):** [https://hard-math-calculator.onrender.com/swagger-ui/index.html](https://hard-math-calculator.onrender.com/swagger-ui/index.html)
*(Перший запит може займати до 50 секунд через особливості холодного старту безкоштовного сервера).*

**🐳 Локальний запуск (Docker Compose):**
Проєкт повністю підготовлений до запуску в ізольованому середовищі.
1. Переконайтеся, що у вас встановлено Docker.
2. Склонуйте репозиторій.
3. У корені проєкту виконайте команду:
   `docker-compose up -d --build`
4. API буде доступне за адресою: `http://localhost:8080/swagger-ui/index.html`
5. Зупинити застосунок: `docker-compose down`
